# Experiment - K-Means Clustering (Country Dataset)

## Aim

To implement K-Means Clustering using Python to group countries based on their socio-economic features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- StandardScaler
- Google Colab
- K-Means Clustering

## Dataset

Country Dataset (`Country-data.csv`)

The dataset contains 167 records and 10 columns:
- Country
- Child Mortality
- Exports
- Health
- Imports
- Income
- Inflation
- Life Expectancy
- Total Fertility
- GDP per Capita

1. Import the required Python libraries.
